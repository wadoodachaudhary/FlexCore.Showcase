    <DocumentationContent>
        <h3>Performance Architecture Overview</h3>
        <p>
            Under traditional Blazor Server architectures, every keystroke and cell navigation event travels over a SignalR circuit WebSocket connection, 
            undergoes server component re-rendering, and returns a binary DOM diff to the browser. Under 50ms+ network latency, this creates perceptible input sluggishness.
        </p>
        <p>
            The <strong>FlexCore Optimizer</strong> eliminates this lag through:
        </p>
        <ul>
            <li><strong>Speculative Local Preview:</strong> The browser immediately positions the active focus border and renders keystrokes into an ephemeral preview overlay.</li>
            <li><strong>Direct Row-Index Caching:</strong> Row positions are cached in indexed dictionaries, turning expensive linear <code>IndexOf</code> scans into O(1) constant-time references.</li>
            <li><strong>Display &amp; Style Memoization:</strong> Format strings, number parsing, and column width calculations are memoized, saving CPU cycles on frequent render cycles.</li>
        </ul>
    </DocumentationContent>
